# Block-printing studio

The visual reference informs typography, fine lines and compact controls. The studio remains centered on designing a printing block, carving its relief and printing onto cloth.

Removed the decorative flower/rock centerpiece and botanical narrative. The opening view now presents the actual drawing canvas within a wood frame, with a concise invitation to add a motif or draw. The carve view uses a quiet support instead of a rock sculpture. Studio light changes the viewing theme.
