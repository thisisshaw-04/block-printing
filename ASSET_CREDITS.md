# Material Assets

The workshop uses scanned CC0 material maps from Poly Haven, bundled locally:

- [Fine Grained Wood](https://polyhaven.com/a/fine_grained_wood): 1K colour and OpenGL normal maps.
- [Rough Linen](https://polyhaven.com/a/rough_linen): 1K diffuse map used for weave relief and neutral fibre variation.
- [Poly Haven asset license](https://polyhaven.com/license).

The textile motifs and geometry are original, inspired by Indian botanical and geometric textile printing. Interface symbols use Lucide. Typography uses DM Sans and Libre Caslon Display via Google Fonts, with system fallbacks.
